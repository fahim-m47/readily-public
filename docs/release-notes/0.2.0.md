Readily 0.2.0 opens EPUB books, PDFs, Word documents and web pages in the composer, not just text files. Four more voice models join the catalog (Qwen3 TTS 1.7B, Supertonic 3, VibeVoice Realtime and VoxCPM2), every cloning model offers twelve consented Voices, and VibeVoice's Mike reads by default.

Readily now runs on Linux too, installed and updated from an apt or dnf repository. Cancel truly stops a Narration, model downloads queue instead of refusing a second click, and every Export lands in one Readily folder in Documents. Readily is now licensed under Apache-2.0.
