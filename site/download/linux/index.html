Readily

Readily for Linux

Readily is packaged for Debian and Ubuntu (apt) and for Fedora (dnf), on x86_64. Add the repository once; after that, your package manager installs Readily and keeps it current with everything else on the machine. Readily tells you at launch when a new version is out, and leaves the install to the package manager.

Debian and Ubuntu

sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL https://readily-download.vercel.app/linux/readily.asc | sudo tee /etc/apt/keyrings/readily.asc >/dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/readily.asc] https://readily-download.vercel.app linux/" | sudo tee /etc/apt/sources.list.d/readily.list
sudo apt update
sudo apt install readily

Fedora

sudo curl -fsSL https://readily-download.vercel.app/linux/readily.repo -o /etc/yum.repos.d/readily.repo
sudo dnf install readily

dnf asks you to accept the repository's signing key the first time. Its fingerprint is in readily.asc.

What the repository signs

The package indexes are signed with the Readily packages key, and each package is named in them by its SHA-256. apt and dnf verify the index's signature and then the package against the index, so a package that was changed on its way to you is refused. The packages themselves carry no signature of their own. The .deb and .rpm are served from the releases on GitHub, where you can also fetch one by hand.

Readily needs a working audio output and an x86_64 processor. The first run downloads the runtime that speaks and a first Voice Model, around 1.2 GB together; narration after that is offline.
